# Règles du projet : Screener Actions

## Langue
- La communication, la documentation et les explications doivent être en français.

## Structure des fichiers
- **Scripts Python (racine)** : `main.py`, `collecte.py`, `config.py`, `controles.py`, `indices.py`, `listes.py`, `macro.py`, `notes.py`, `referentiels.py`, `rendu.py`, `retro.py`, `retro_us.py`, `sante.py`, `temoin.py`, `temoin_large.py`, `univers.py`.
- **Interface Web (`web/`)** : Fichiers HTML (`index.html`, `retro.html`, `tableau.html`), JavaScript (`app.js`, etc.) et CSS (`style.css`).
- **Tests (`tests/`)** : Tests unitaires correspondants (`test_*.py`).
- **Données (`data/`)** : Fichiers JSON, CSV, estimations.

## Règles de développement
- **Affichage du diff** : Toujours montrer explicitement le diff des modifications proposées avant de toucher ou d'appliquer des changements au code.
- Respecter rigoureusement les conventions et le style existants du projet.
